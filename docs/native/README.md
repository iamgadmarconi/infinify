# Infinify native code

The Objective-C code of Infinify, the macOS port of DriftWM: the canvas panels, window capture, input routing and run lifecycle around the Rust controller in `crates/desktop` (which uses `crates/core` and `crates/canvas`). A normal run is the desktop: it replaces the native one ([Desktop mode](user-guide.md#desktop-mode)). It lives in `native/app` (the shell, one directory per module) and `native/dock-helper` (the Dock helper that compositor mode needs), with its tests and fixture programs in `tests/native`. These documents are the shell's and the helper's account of themselves: [user-guide.md](user-guide.md) for running and configuring Infinify, one document per module below, and [testing.md](testing.md).

The parity contract, [docs/parity/README.md](../parity/README.md), keeps what these documents describe at `implemented_unverified` or below, and says what is still open. Nothing in them is `verified`.
