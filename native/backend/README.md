# Native backend and fixture

The Rust crate `driftwm-macos-backend` owns validation, identity checks, lifetime,
subprocess protocol, snapshots, restoration and capability reports. Objective-C
is limited to AppKit/CGWindow/AX adaptation and dynamically loaded SkyLight calls.
Build with Xcode command-line tools, macOS SDK 26 or newer and Rust 1.88 or newer.
The native adapter deployment target is macOS 26.

```
cargo build -p driftwm-macos-backend --bins --locked
target/debug/driftwm-native-probe doctor
target/debug/driftwm-native-probe list
tests/e2e/native-fixture.sh
```

The executable without arguments runs read-only doctor. `probe` explicitly opens
one disposable native fixture and briefly transforms and clicks its own native
button, then restores the transform, pointer, and closes the fixture. The fixture
has actual AppKit editable text, a button, scrolling content and a popup. It joins
the current Space (including full-screen apps); it does not change Spaces or user
settings. AX and capture checks never request permissions.

`doctor()`, `list_windows()`, `probe_fixture()` return serializable JSON evidence.
`FixtureSession::spawn()` verifies a random nonce and the PID of the exact child.
Its private enrollment stores process birth time, window id and WindowServer
connection. `snapshot()`, `snapshot_window(&WindowIdentity)` and
`with_placement(&OutputPlacement, callback)` validate these identities again.
Publicly constructed snapshots cannot authorize mutation. `TransformGuard` saves
the actual native matrix, marks every setter attempt dirty even on error, checks
restoration explicitly, and retries restoration on Drop. The subprocess server
also restores any held transform on EOF, normal exit, or its 60-second deadline.
This does not guarantee recovery from SIGKILL or process-wide abort; fixture-only
scope makes the child window disposable. General user-window crash recovery is
outside this backend's enrollment policy.

An `OutputPlacement` takes a WindowServer screen-to-buffer affine transform in
logical points. It is not a world-to-screen camera transform; the caller must
invert the desired presentation mapping. More than one live presentation per
window and any clipping request fail explicitly. Nonfinite/singular transforms,
invalid native bounds, stale process birth and owner identities fail before
mutation. There remains an unavoidable OS race between identity query and setter;
there is no atomic compare-and-set API here.

Input proof uses `CGEventPost(kCGHIDEventTap)`, never app-local synthetic dispatch.
Before posting, the probe requires a successful setter, readback matching the
requested nonunit transform, changed screen rectangle, current identity, and a
visible fixture target unobscured by any higher window. If a higher window's
screen rectangle cannot be queried, it refuses input. Events carry a unique
probe marker; proof requires marked events, native button action, and expected
local coordinates. The pointer is restored after the bounded click sequence.
Window ordering can still change between query and event delivery; this is a
fixture diagnostic, not a safe generic input router.

## Observed runtime result

`evidence/final-probe.json` records a live run on Apple Silicon macOS 27.2,
build 26B5091g, in the host's SIP-enabled configuration (SIP status supplied by
coordinator; this crate does not change or disable SIP):

- Own process: setter status 0, readback matches requested transform, actual
  WindowServer screen rectangle changes, and actual original matrix restores.
- Same-user foreign process: setter status **0**, but actual transform and screen
  rectangle remain unchanged. The capability is correctly reported false.
- Scaled native button: two marked mouse-down events, two native actions, expected
  local coordinates; pointer restoration status 0 and original matrix restored.
- Keyboard editing, scrolling, popup input and multiple simultaneous live
  presentations are not proven. A functioning button does not establish them.

`latest-probe.json` is the focused E2E receipt and is regenerated by the runner.
`input-probe.json` preserves earlier exploratory input evidence; it predates the
strict tagged-event and transform validation gates and must not be preferred over
the final receipt. A denied/occluded input report is a valid unsupported runtime
result, not permission to bypass the guard.

## Source provenance

All implementation here is new GPL-3.0-or-later code. No upstream implementation
was copied, including yabai's assumed-original-transform reset.

- yabai at `dd845723416f5fe92af49fad5ebab00369e07edd`,
  `src/osax/payload.m` (`do_window_scale`, native declarations):
  https://github.com/koekeishiya/yabai/blob/dd845723416f5fe92af49fad5ebab00369e07edd/src/osax/payload.m
  Used to check private ABI signatures and scale behavior. Upstream is MIT;
  its implementation is not vendored or copied by this backend.
- Mozilla Gecko `widget/cocoa/nsCocoaWindow.mm`, `SetWindowTransform`:
  https://github.com/mozilla/gecko-dev/blob/master/widget/cocoa/nsCocoaWindow.mm
  Reference for screen-to-window-buffer inversion and logical point coordinates.
  This is a moving reference, not a pinned source dependency.
- NUIKit/CGSInternal `CGSWindow.h`, `CGSGetScreenRectForWindow` declaration:
  https://github.com/NUIKit/CGSInternal/blob/master/CGSWindow.h
  Used to check the screen-rectangle ABI; `SLSGetScreenRectForWindow` is dynamically
  resolved and successful runtime output is recorded separately from availability.
